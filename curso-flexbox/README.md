# Curso _Flexbox CSS_

Los códigos de mi [Curso de _Flexbox CSS_](https://www.youtube.com/playlist?list=PLvq-jIkSeTUbQc3dGsssp8lxAi5npMrys): 13 videos en los que te enseño todo lo que necesitas saber sobre _Flexbox_, el sistema de maquetación unidimensional de _CSS_, para acomodar los elementos de tus componentes: tarjetas, menús, formularios y botones.

## Archivos

| Archivo        | Videos                                                                                                | Qué hay                                                                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `flexbox.html` | [1](https://www.youtube.com/watch?v=AAtvnv6LNMk) a [9](https://www.youtube.com/watch?v=u-k1kPtOA5o)   | Los conceptos básicos y cada una de las propiedades del contenedor padre y de los elementos hijos.                                                                       |
| `index2.html`  | [10](https://www.youtube.com/watch?v=KoLOOETh0f4)                                                     | Una _grid_ de maquetación _responsive_ hecha a mano con _Flexbox_.                                                                                                       |
| `index.html`   | [10](https://www.youtube.com/watch?v=KoLOOETh0f4)                                                     | La misma _grid_ con _Bootstrap_ 4, para ver cómo funciona por dentro gracias a _Flexbox_.                                                                                |
| `index3.html`  | [11](https://www.youtube.com/watch?v=9TcStLE3qzI) y [12](https://www.youtube.com/watch?v=po9V3IoxbJc) | Seis casos prácticos: _sticky footer_, cabecera _responsive_ con logo y menú, _hero image_, centrado perfecto, maquetación _zig zag_ y _responsive_ sin _media queries_. |
| `index4.html`  | [13](https://www.youtube.com/watch?v=z11iV2JKHVc)                                                     | Los mismos casos prácticos, pero solo con las clases utilitarias de _Flexbox_ de _Bootstrap_ 4.                                                                          |

`index.html` e `index4.html` cargan _Bootstrap_ 4 desde su _CDN_, así que necesitas internet para verlos.
