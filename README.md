# Maquetación Web 🧱

Hola, soy tu amigo y docente digital **Jonathan MirCha**, bienvenid@s a mis cursos de maquetación _web_.

En este repositorio encontrarás los códigos de mis cursos de maquetación con _CSS_ de mi canal de [_YouTube_](https://youtube.com/@jonmircha). Juntos, _Flexbox_ y _Grid_ son una filosa navaja suiza 😎🪒: _Flexbox_ acomoda lo de adentro de cada componente y _Grid_, la estructura de la página.

## Cursos

| Curso                                                                                           | Videos | Códigos                            |
| ----------------------------------------------------------------------------------------------- | :----: | ---------------------------------- |
| [Curso _Flexbox CSS_](https://www.youtube.com/playlist?list=PLvq-jIkSeTUbQc3dGsssp8lxAi5npMrys) |   13   | [`curso-flexbox`](./curso-flexbox) |
| [Curso _Grid CSS_](https://www.youtube.com/playlist?list=PLvq-jIkSeTUY628cyd9LVbXSXi2xG9mUl)    |   17   | [`curso-grid`](./curso-grid)       |

Te recomiendo empezar por _Flexbox_ y seguir con _Grid_.

## Cómo usar los códigos

No necesitas instalar nada: clona o descarga el repositorio y abre cualquier archivo `.html` en tu navegador.

```bash
git clone https://github.com/jonmircha/youtube-maquetacion-web.git
```
